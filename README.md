# GTA 6 Fan Site – Projet Programmation Web (EFREI)

Site de fans sur Grand Theft Auto VI, réalisé en HTML, CSS et JavaScript pour le projet TI504N.

## Équipe

- Amir Arioui
- Amine Razouk
- Ilyes

## Ouvrir le site

Ouvrir `index.html` dans un navigateur, ou avec l'extension Live Server de VS Code.

## Arborescence

```
index.html              → page d'accueil
pages/personnages.html  → les personnages du jeu
pages/a-propos.html     → l'équipe et les sources
css/style.css           → le style du site
js/script.js            → compte des jours avant la sortie + boutons « Plus d'infos »
img/                    → les images
maquette/               → la maquette (wireframe) en PDF
```
